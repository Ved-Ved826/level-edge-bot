Задача: вынести всю денежную математику биржи в чистые функции без I/O и покрыть их тестами инвариантов. ПОВЕДЕНИЕ ПРОДАКШЕНА ДОЛЖНО ОСТАТЬСЯ ТОЧНО ТАКИМ ЖЕ (комиссии пока прежние: покупка +6%, продажа -5%).

1. Создай `worker/src/exchange/constants.ts` со всеми константами из EXCHANGE_2_RULES.md (§4). На этом шаге значения комиссий выставь ПРЕЖНИЕ, чтобы результат был байт-в-байт как сейчас: покупка totalCost = ceil(baseCost * 1.06), founderFee = floor(baseCost * 3 / 100), reserveFee = остаток; продажа netPayout = floor(basePayout * 95 / 100), reserveCut = остаток. Новые комиссии (4%/3%) добавим на шаге 6 отдельным коммитом. Если для этого нужны временные «legacy»-константы, заведи их с явным комментарием.

2. Создай `worker/src/exchange/math.ts` — чистые функции, БЕЗ доступа к БД и времени (время передаётся параметром):
   - circulating(availableShares), navX100(treasury, circulating) (floor до 2 знаков, как в /stocks);
   - quoteBuy({ amount, treasury, circulating, moodBps }) -> { baseCost, premium, founderFee, reserveFee, totalCost, treasuryDelta, founderDelta, reserveDelta, moodShiftBps };
   - quoteSell({ amount, treasury, circulating, moodBps }) -> { basePayout, discount, grossPayout, netPayout, reserveCut, treasuryDelta, reserveDelta, moodShiftBps };
   - effectiveMood(moodBps, updatedAtSec, nowSec) и applyMoodShift(moodBps, shiftBps);
   - dailyGrowthGrant(treasury, reserveBalance).
   Логику настроения реализуй уже сейчас по спецификации из EXCHANGE_2_RULES.md (§3), но обработчики пока ВСЕГДА передают moodBps = 0 и игнорируют moodShiftBps. Так при moodBps = 0 премия и скидка равны 0 и результат совпадает со старой формулой.
   Формулы настроения (m = эффективное настроение в bps, k = amount, T = treasury, C = circulating до сделки):
     покупка: premium = m > 0 ? ceil(baseCost * m / 10000) : 0; в казну уходит baseCost + premium.
     продажа: discount = m < 0 ? ceil(basePayout * (-m) / 10000) : 0; grossPayout = basePayout - discount; из казны уходит grossPayout (казна остаётся с discount).
     сдвиг настроения: shift = min(MOOD_MAX_SHIFT_PER_TRADE_BPS, round(MOOD_IMPULSE_BPS * k / C)); покупка +shift, продажа -shift; итог обрезается в [-2500, 2500].
     затухание: trunc(m * 0.5 ** (dtHours / MOOD_HALF_LIFE_HOURS)), усечение к нулю.
   Все деньги — целые числа, только floor/ceil. Комментарий к каждой формуле: зачем она такая.
