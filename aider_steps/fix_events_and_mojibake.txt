Выполни две важные задачи: упрощение кризисов до автоматических событий и полное исправление сломанной кодировки (кракозябр) в русском тексте.

====================================================================
ЗАДАЧА 1. ИСПРАВЛЕНИЕ КРАКОЗЯБР И РУССКОГО ТЕКСТА (collector/src/collector.ts)
====================================================================
В файле collector/src/collector.ts найди и замени все повреждённые русские строки (mojibake вида "РЎР•Р»Р...", "рџЏ†", "РћРїРёСЃР°РЅРёРµ") на чистый русский текст UTF-8:

1. В функции разблокировки достижений (unlockAchievement) и везде вокруг ачивок:
   - Заголовок эмбеда: `🏆 СЕКРЕТНОЕ ДОСТИЖЕНИЕ РАЗБЛОКИРОВАНО!`
   - Описание: `<@${userId}> открыл(а) секретное достижение **«${achievement.title}»**!`
   - Названия полей: `Описание`, `Цитата`, `Награда` (`+${achievement.reward_xp} XP`)
   - Футер: `Открыто секретов: ${unlockedCount}/${totalCount}`

2. В описаниях всех слэш-команд (массив команд биржи, а также команды города):
   - map: `Город: интерактивная карта участков и недвижимости`
   - plot: `Город: управление участками недвижимости`
   - build: `Город: построить бизнес на своём участке`
   - upgrade: `Город: улучшить здание на участке (до уровня 3)`
   - auction: `Город: аукционы участков недвижимости`
   - exchange-setup: `Канал для публичной ленты биржи (Manage Server)`
   - exchange-top: `Рейтинг инвесторов и компаний сезона по ROI`

3. В цикле регистрации команд на серверах (client.on('ready') / clientReady):
   Обязательно добавь вызов edit для уже существующих команд, чтобы Discord принудительно обновил старые битые описания на новые:
   ```ts
   if (existingCmd) {
     await existingCmd.edit(cmd);
   } else {
     await guild.commands.create(cmd);
   }
   ```

4. Проверь системные уведомления бота (Happy Hour, стрики активности, дейлики, газета): если там встречаются битые строки вроде "РЎС‡Р°СЃС‚Р»РёРІС‹Р№ С‡Р°СЃ", верни им нормальный русский текст ("Счастливый час", "Ежедневная активность" и т.д.).

====================================================================
ЗАДАЧА 2. АВТОМАТИЧЕСКИЕ СОБЫТИЯ КОМПАНИЙ ВМЕСТО КНОПОК
====================================================================
1. В collector/src/crises.ts:
   - Полностью убери интерактивный выбор кнопками, ожидание дедлайнов и 24-часовые таймауты.
   - Сделай события мгновенными (автоматическими):
     * При срабатывании тикера выбирается компания и сразу применяется событие:
       - 50% шанс ПОЛОЖИТЕЛЬНОГО события (Госзаказ, Прорыв технологий, Успешный маркетинг, Рекордный квартал, Инвестиционный бум):
         Казна компании `treasury` увеличивается на 10% - 25% (минимум +150 🪙).
       - 50% шанс ОТРИЦАТЕЛЬНОГО события (Налоговая проверка, Сбой оборудования, Утечка данных, Судебная издержка, Скандал в прессе):
         Казна компании `treasury` уменьшается на 5% - 20% (но не ниже 50 🪙).
     * Изменение казны применяется МГНОВЕННО через UPDATE companies SET treasury = ...
     * Записывай событие в company_crises сразу со статусом 'resolved' (для сохранения истории).
     * Добавляй запись в company_nav_history с reason 'crisis'.
     * Отправляй в market_events сочный анонс для ленты Discord:
       Для положительного: `🎉 **Событие компании:** У **${name}** (\`${ticker}\`) прорыв: ${title}! Казна выросла на **+${delta} 🪙**!`
       Для отрицательного: `📉 **Инцидент:** Компания **${name}** (\`${ticker}\`) понесла убытки: ${title}. Казна сократилась на **-${delta} 🪙**.`
   - При старте бота автоматически закрой все старые зависшие кризисы:
     `UPDATE company_crises SET status = 'resolved' WHERE status = 'pending'`

2. В worker/src/commands/stocks.ts:
   - Убери запрос активных кризисов из company_crises со статусом 'pending' и удали строку `⚠️ Кризис: осталось...`, чтобы список акций был чистым.

3. В worker/src/worker.ts:
   - Убери или заглуши обработчик кнопок `crisis:` (кнопок больше нет).
