Твоя задача — реализовать хардкорную RPG-экономику, кузницу с кулдауном, элитные титулы, а также полную нативную поддержку развертывания коллектора на Android/Termux (Samsung A25, arm64). Используй точечные SEARCH/REPLACE diff блоки.

---

### 1. ДРОП С БОССОВ И НЕРФ ПРИЗОВЫХ (worker/src/worker.ts)
В ветке смерти босса (newCurrentHp <= 0):
1. Сильно снизь награду монет за победу:
   - Мимик дает 75 монет, остальные боссы (дракон, левиафан, фантом) — по 40 монет. Опыт (XP) оставь прежним.
2. Реализуй хардкорный дроп экипировки из itemsCatalog.ts:
   - Шанс для Топ-1 дамагера: ровно 5% (Math.random() < 0.05).
   - Шанс для остальных участников: ровно 3% (Math.random() < 0.03).
3. Если шанс сработал: выбери случайный предмет из UNIQUE_ITEMS, проверь его уникальность через isItemUniqueOnServer и добавь запись в user_inventory.
4. В victoryEmbed добавь строку с выпавшим лутом (если кому-то повезло).

### 2. КУЗНИЦА С КУЛДАУНОМ 12 ЧАСОВ (/forge) (worker/src/worker.ts)
Добавь обработку слэш-команды /forge id:number:
1. Кулдаун: 1 раз в 12 часов (проверяй поле last_forge_at в таблице users, если колонки нет — делай безопасный fallback). Если 12 часов не прошло — выводи сообщение, сколько часов и минут осталось до следующей попытки.
2. Стоимость попытки заточки: 1500 монет (проверяй coins >= 1500).
3. Логика заточки:
   - Находит предмет в user_inventory игрока по переданному ID.
   - Списывает 1500 монет и обновляет last_forge_at.
   - Шанс успеха: 60%.
   - При успехе: увеличивает atk_bonus += 15 и def_bonus += 10, а к item_name приписывает [+1].
   - При неудаче: монеты сгорают, предмет сохраняется, выводится сообщение: "Кузнец оплошал! Заточка сорвалась, 1,500 монет улетели в трубу."

### 3. ЭЛИТНЫЙ МАГАЗИН ТИТУЛОВ И ЗАМОРОЗОК (/shop) (worker/src/worker.ts)
В слэш-команде /shop:
1. Заморозка стрика (freeze): цена 1800 монет (проверяй coins >= 1800, списывай монеты и делай streak_freezes + 1).
2. Престижные титулы (покупка списывает монеты и сохраняет title_id в user_cosmetics):
   - "Майонез" — цена 5000 монет
   - "Господин" — цена 15000 монет
   - "Навальный" — цена 30000 монет
   - "Царь-Батюшка" — цена 50000 монет
   - Перед покупкой строго проверяй баланс монет. При успехе выводи: "Вы приобрели статус {title}! Теперь он отображается на вашей карточке /rank!"

### 4. ПЛАТНАЯ КАСТОМИЗАЦИЯ И СЕЛЛ (/card-customize, /sell-junk, /settings) (worker/src/worker.ts)
1. В card_select_theme: тема default бесплатная, темы cyberpunk, magma, midnight, emerald стоят по 3500 монет каждая.
2. В /sell-junk: добавь опциональный параметр item_id. Если передан — продавать только этот предмет из инвентаря, иначе продавать весь junk.
3. В /settings level-notify [step]: настройка шага уведомлений о новом уровне (0 - выкл, 1, 5, 10, 20). По умолчанию 10.

### 5. ПОДДЕРЖКА ЗАПУСКА НА ТЕЛЕФОНЕ ЧЕРЕЗ TERMUX (package.json, collector/package.json, setup-termux.sh)
1. В collector/package.json добавь в "scripts":
   `"build": "tsc -p tsconfig.json"`
   чтобы `npm run build -w collector` работал без ошибки Missing script.
2. В корневом package.json добавь скрипты:
   `"termux:install": "npm install --force --ignore-scripts"`
   `"termux:build": "npm run build -w shared && npm run build -w collector"`
   `"termux:start": "npm run start -w collector"`
3. Создай в корне репозитория скрипт `setup-termux.sh` для автоматического запуска на Samsung A25 / Android:
   - Включает `termux-wake-lock`
   - Запускает установку через `--ignore-scripts` (обход ошибки workerd на arm64)
   - Компилирует shared и collector
   - Создает автозапуск в `~/.termux/boot/start-bot.sh` с PM2
   - Запускает бота через `pm2 start dist/collector.js --name disbot` и делает `pm2 save`.

Примени все изменения точечными diff блоками.
