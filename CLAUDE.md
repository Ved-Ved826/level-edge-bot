# LevelEdge — Developer Agent Contract

## 1. Стек и рабочее пространство
- Корень: `E:\disbot`. Команды исполнять строго из корня или явным переходом в каталог подсистемы.
- `/collector` (Node.js/Render): WebSocket Gateway, войс/текст трекинг, боссы, таймеры.
- `/worker` (Cloudflare Workers): HTTP Interactions, slash-команды, карточки Satori+WASM.
- БД: Turso (libSQL/SQLite) через `@libsql/client`. DDL схемы: `schema.sql`.

## 2. Безопасность процессов (Windows / Omniroute)
- ❌ **СТРОЖАЙШЕ ЗАПРЕЩЕНО**: `taskkill /F /IM node.exe`, `killall node` и любые групповые убийства процессов!
- На порту `20128` работает шлюз Omniroute (сессия LLM). Убийство обрывает связь.
- Завершение процессов ТОЛЬКО по выделенному PID:
  1. `netstat -ano | findstr :<PORT>`
  2. `taskkill /PID <PID> /F`
- Запись файлов: только инструменты редактирования агента или `node -e "fs.writeFileSync(...)"` (без неэкранированного `cat << EOF`). UTF-8 без BOM.

## 3. Инварианты данных
- **Мультигильдийность**: В таблицах `users`, `world_boss`, `city_plots`, `company_crises`, `user_inventory` ЛЮБОЙ `SELECT`, `UPDATE`, `DELETE` ОБЯЗАН содержать `WHERE guild_id = ?` (или `<alias>.guild_id = ?`).
- **Батчинг**: Множественные мутации в БД объединять строго в `db.batch([...])`. Запрещены циклы с `await db.execute()`.

## 4. Контроль контекста и поведение
- Стиль: строго русский язык, ноль воды/приветствий, краткий факт сделанного.
- Запрещено читать файлы >150 строк целиком. Использовать `grep` и точечное чтение диапазона строк.
- Для задач ≤ 2 файлов и ≤ 30 строк Plan Mode запрещен — вносить точечные правки сразу.
- Никаких догадок по полям БД — проверять сигнатуры в коде или в `schema.sql`.
- Никакого попутного рефакторинга соседнего кода.

## 5. Протокол проверки и коммита
- Правки в `/collector` → `cd E:\disbot\collector && npx tsc --noEmit`
- Правки в `/worker` → `cd E:\disbot\worker && npx tsc --noEmit`
- Не завершать задачу без подтверждения 0 ошибок компиляции.
- Git: `git add <файлы>` (без мусора) → `git commit -m "<type>: <описание на русском>"`.
