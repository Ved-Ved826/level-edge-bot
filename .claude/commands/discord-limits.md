Проверь все Embed-сообщения и конфигурации слэш-команд в измененных файлах на жесткие лимиты Discord API:
1. Embed title <= 256 символов.
2. Embed description <= 4096 символов.
3. Полей в Embed (fields) <= 25 штук.
4. Значение поля (value) <= 1024 символа, название (name) <= 256 символов.
5. Суммарный размер всего Embed <= 6000 символов.
6. В слэш-командах: name только в нижнем регистре (1-32 символа, без пробелов), description <= 100 символов.
Если найдешь превышение — сразу укажи точную строку и сократи текст.
